GOMAJI Carnival City
Key Visual and Website

  • Key visual
  • Website UI
  • HTML/CSS implementation

I designed the event visuals and responsive website for GOMAJI Carnival City, building on GOMAJI’s existing brand assets and Maji Friend characters. The single-page site brought together event highlights, practical information, and links to buy tickets.

Visit live site ↗
Client
GOMAJI
Role
Key visual, website UI, HTML/CSS implementation
Timeline
3 weeks: 1.5 for planning, 1.5 for design
Event: Jun 2023
Tools
Photoshop · Illustrator · Sublime Text

What I did

Using GOMAJI’s existing logo, Maji Friend characters, and brand elements, I created the event’s key visual—the city backdrop, title treatment, color palette, and composition. I adapted it for the website and printed event materials.

I designed the website UI and built it in responsive HTML/CSS, using an animation plugin for the title effects. The PM set the event direction and outlined the required content. With a tight schedule, I developed the page structure alongside the visual design. Engineers handled platform integration and deployment.
